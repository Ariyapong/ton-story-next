The site you're looking at. Bilingual EN/TH editorial layout with three
themes (milk, coffee, tea) and an unstyled `/` homepage as a small joke for
anyone who reads source.

เว็บที่คุณกำลังดูนี้เอง — เลย์เอาต์เชิงบรรณาธิการแบบสองภาษา EN/TH
มีสามธีม (นม กาแฟ ชา) และหน้า `/` ที่จงใจปล่อยไม่ใส่ CSS
เป็นเรื่องเล่นเล็ก ๆ สำหรับคนที่อ่านซอร์ส

## What it is

- One repo. Next.js 15 App Router, React 19.
- Posts and projects as `.mdx` files in `content/`.
- Three themes wired through CSS variables — no JS class swapping.
- IBM Plex Serif + Plex Sans Thai Looped for matching bilingual rhythm.

## Why I built it from scratch

The previous version was a starter template I never grew into. Editing it
felt like decorating a hotel room. Building from scratch lets the structure
match how I actually write.
