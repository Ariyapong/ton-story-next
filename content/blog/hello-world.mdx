# Hello, world

Welcome to the first post on the rebuilt **Ton Story**. I tore down the old
starter-template scaffolding and rebuilt the site on Next.js 15, React 19, and
Tailwind v4. Posts live in MDX so I can mix prose with React components.

## Why MDX

- Frontmatter for titles, dates, tags
- Plain markdown for fast writing
- React components when I need something interactive
